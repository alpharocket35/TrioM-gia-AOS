# AOS de TrioMégia

Un faux système d'exploitation entièrement dans le navigateur.

## Fonctionnalités
- Bureau et icônes
- Fenêtres déplaçables, redimensionnables et minimisables
- Barre des tâches
- Menu Démarrer
- Explorateur de fichiers virtuel
- Notes avec sauvegarde dans localStorage
- Calculatrice
- Terminal virtuel avec commandes
- Navigateur de démonstration
- Lecteur musical d'interface
- Paramètres et thèmes
- Horloge en temps réel
- Notifications
- Persistance locale
- Responsive

## Installation GitHub Pages

1. Crée un dépôt GitHub.
2. Copie tous les fichiers du projet.
3. Push sur la branche `main`.
4. GitHub > Settings > Pages > Source: GitHub Actions.
5. Le workflow `.github/workflows/pages.yml` publiera automatiquement le dossier.

Aucun backend, aucune base de données et aucune carte bancaire ne sont nécessaires.

## Important
Les fichiers et notes sont stockés uniquement dans le navigateur via `localStorage`. Ce n'est pas un vrai cloud.


## TrioGaming

AOS inclut un portail de jeux intégré appelé **TrioGaming**.
Le portail utilise une identité visuelle orange et noire et peut servir de hub
pour des jeux HTML5 ajoutés au projet.

## Identité visuelle

- AOS clair : bleu ciel + blanc
- AOS sombre : jaune + noir
- TrioGaming : orange + noir
